```yaml
name:       Li Hang (Henry)
location:   Singapore
studying:   Computer Science + Data Science @ NTU
building:   agent harnesses · dev tooling · things that automate my own life
philosophy: ship it ugly, then make it sharp
```

**What I actually enjoy:** hard problems where the answer isn't googleable, tools with real users (even if that's one user and it's me), and understanding *why* a design won — not just copying it.
